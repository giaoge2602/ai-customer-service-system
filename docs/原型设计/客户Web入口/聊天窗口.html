💬 客户 Web 入口 · 设计要点

F-029 客户网页入口 F-035 嵌入式客服 F-026 满意度评价 F-030 多端同步

两种形态

  • Web Widget 嵌入式（左侧预览）：通过 <script> 嵌入第三方网站，悬浮气泡 + 弹出聊天面板
  • 独立聊天窗口：租户子域名（如 {tenant}.support.com）全屏聊天页

当前状态：AI 接待中

折叠 欢迎 AI 接待中 排队中 人工接待 结束 离线

关键能力（V1）

  • 消息类型：文本 · 图片（≤10MB） · 文件（≤50MB）
  • AI 引用卡：知识来源 + 文档摘录，点击可查看完整
  • 快捷问题预填：客户点击直接发送
  • 转人工：客户可主动触发，AI 也可在低置信度 / 敏感词 / 客户要求时自动触发
  • 多端同步：消息在 PC 客服工作台实时同步

消息流设计原则

  • 客服 / AI 气泡：圆角 + 颜色区分（AI 蓝紫渐变 / 人工绿）
  • 客户气泡：右对齐，主色渐变（保留品牌色）
  • 系统消息：居中灰色，常用于"AI 已转人工"等关键节点
  • 思考中：动态三圆点，避免空白等待
  • 引用卡片：左色条 + 标题 + 内容，传达"这是 AI 引用知识"的可信度

隐私与合规（F-041）

  • 首次进入：必须勾选隐私同意才能发送消息
  • 侧边入口：随时查看、撤回同意、申请数据导出/删除
  • 撤回同意后：会话可继续但客户档案对客服自动脱敏

评价（F-026 V1 简化）

会话结束后 5 分钟内弹评价卡：1-5 星 + 标签多选（响应及时 / 专业 / 态度好 / 解决问题 / 不满意）+ 50 字文字。
不评价视为放弃，不打扰。评价结果进入租户运营报表。

多端实时同步（F-030）

  • 消息：毫秒级同步（Socket.io）
  • 会话状态：转接 / 结束 / 评价实时可见
  • 客服在线状态：影响客户端显示"X 位客服在线"
  • 断线重连：自动重连 + 消息补齐，避免丢消息

移动端

Widget 在移动端自动全屏展示，顶部关闭按钮收起为气泡。输入区支持语音转文字（V1 简化为只能键入，二期 F-021 支持语音消息）。
