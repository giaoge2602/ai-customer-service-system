# Nginx 生产部署接入说明

> 日期：2026-08-25 ｜ 状态：✅ 已部署运行

## 一、部署架构

```
浏览器 ──► http://localhost:80  (Nginx 统一入口)
              │
              ├── /                 → 前端静态资源（dist/ 生产构建）
              ├── /workbench/*      → SPA 路由回退到 index.html
              ├── /api/             → 反向代理 → http://127.0.0.1:4000（NestJS）
              └── /api/docs         → 反向代理 → 后端 Swagger
```

## 二、使用的 Nginx

- **版本**：nginx/1.22.0（用户已有资源）
- **位置**：`D:\web\nginx\nginx-1.22.0-web\`
- **原配置备份**：`conf/nginx.conf.bak-20260825`

> 另一份 `D:\nginx\nginx-1.18.0\` 未使用，保留原样。

## 三、核心配置（conf/nginx.conf）

| 配置项 | 值 |
| --- | --- |
| 监听端口 | 80 |
| worker_processes | 4（原 auto 会按 32 核起 32 个 worker） |
| 前端根目录 | `D:/ai-customer-service-system/dist` |
| SPA 回退 | `try_files $uri $uri/ /index.html` |
| API 反代 | `location /api/ → http://127.0.0.1:4000`（保留路径前缀） |
| 静态缓存 | js/css/图片 7 天（带 hash 文件名） |
| Gzip | 开，level 5，覆盖 js/css/json/svg |
| WebSocket | 已配 Upgrade/Connection 头（供后续实时功能） |

## 四、启动 / 停止 / 重载

```bash
# 启动（注意：Git Bash 直接运行会被沙箱拦截，需 PowerShell Start-Process 或非沙箱）
cd D:\web\nginx\nginx-1.22.0-web
nginx.exe -p D:/web/nginx/nginx-1.22.0-web/

# 停止全部
taskkill /IM nginx.exe /F        # 或 PowerShell: Get-Process nginx | Stop-Process -Force

# 改配置后重载（不中断服务）
nginx.exe -p D:/web/nginx/nginx-1.22.0-web/ -s reload

# 校验配置
nginx.exe -t -p D:/web/nginx/nginx-1.22.0-web/
```

## 六、注意事项

1. **访问入口变为 80 端口**：以后直接用 `http://localhost/` 访问，不再依赖 5180（开发）/ 5173（CodeWhisper 占用）。
2. **前端发版**：重新 `npm run build` 后 Nginx 无需重启，静态文件实时生效。
3. **后端必须先在 4000 端口运行**（`node dist/main.js`），否则 `/api` 返回 502。
4. **前端 API 代理**：生产构建默认请求同源 `/api`，正好走 Nginx 反代；开发时 Vite 5180 的 `/api` 代理指向 4000，互不影响。
5. 部署目录与前端工程分离：Nginx 只读 `dist/`，与源码改动解耦。
