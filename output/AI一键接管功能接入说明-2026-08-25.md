# AI 一键接管功能 · 接入说明

> 日期：2026-08-25 ｜ 模块：会话工作台 `/workbench` ｜ 状态：已搭建完成（本地模拟引擎），真实大模型 API 接入点已预留

## 一、功能概述

在客服会话工作台聊天窗口头部新增 **「AI 接管」** 按钮，解决客服繁忙 / 下班 / 休息时段无人接待的问题：

- **一键接管**：点击「AI 接管」→ 会话状态切换为「AI 接待」，插入系统提示消息，AI 自动生成实时回复，输入区禁用（防止人工误发）
- **随时收回**：AI 接待中按钮变为「收回人工」，点击即可恢复人工发送权限
- **状态可见**：聊天窗口顶部出现「AI 正在接待本会话」横幅，客户侧感知 AI 实时服务

## 三、接入真实大模型（后续步骤）

当前 `AI_TAKEOVER.provider = 'local-mock'`（本地模拟，开箱即用）。接入真实大模型只需两步：

1. **后端（NestJS）新增代理接口**：`POST /api/v1/ai/chat`
   - 接收 `{ conversationId, reason, messages, system }`
   - 转发到 DeepSeek / 通义千问等大模型（密钥放服务端环境变量），返回 `{ reply }`
2. **前端切换开关**：将 `src/aiService.js` 中 `AI_TAKEOVER.provider` 改为 `'backend-proxy'`
   - `requestAiReplyRemote()` 已实现 fetch 调用（自动带历史消息与 Bearer Token）
   - 若后端暂未实现，也可改用 `'openai-compatible'` 直连（需在前端配置 baseURL/密钥，仅建议内网或测试环境）

```js
// src/aiService.js 关键配置
export const AI_TAKEOVER = {
  enabled: true,
  provider: 'local-mock',          // 改为 'backend-proxy' 即接入后端大模型代理
  apiUrl: '/api/v1/ai/chat',       // 后端代理地址
  replyDelay: 900,
}
```
