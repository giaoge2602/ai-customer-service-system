# AI 智能客服系统 V1（数据底座版）设计文档（简化版）

## 1. 产品概述

### 1.1 产品定位

面向企业/机构的多租户智能客服平台，核心能力为"AI 优先接待 + 人工可控接管 + 全渠道统一会话 + 知识驱动回答 + 数据化持续运营"。

### 1.2 本期范围（V1 数据底座版）

1. 核心实体数据管理：租户、客服账号、客户、会话、消息、平台配置、角色权限；
2. 三端界面协同：平台管理后台、租户运营后台、PC 客服工作台；
3. 客户 Web 入口：Web Widget 与独立聊天窗口；
4. 多端实时同步：消息、会话状态、在线状态、未读数。

AI 问答、知识库、客服路由、运营报表等业务能力二期对接。

### 1.3 核心角色（7 类）

| 角色 | 层级 | 职责 |
| --- | --- | --- |
| 超级管理员 | 平台级 | 租户、套餐配额、平台 AI 模型、全局统计与审计 |
| 租户管理员 | 租户级 | 本机构客服、客户、知识库、渠道、运营规则 |
| 客服主管 | 租户级 | 排班、技能组、会话监控、质检、绩效 |
| 客服人员 | 一线 | 接待会话、客户资料、转接/工单、结束会话 |
| AI 客服 | 系统 | 意图识别、知识检索、回答生成、转人工判断 |
| 客户 | 外部 | 发起咨询、消息、评价、隐私管理 |
| 第三方系统 | 外部 | Open API/Webhook 集成 |

## 2. 系统架构总览（5 大系统）

| 系统 | 用户 | 定位 | 一级菜单 |
| --- | --- | --- | --- |
| 1 平台管理后台 | 超级管理员 | 租户治理、资源配额、AI 模型、审计 | 平台总览 / 租户管理 / 平台配置 / 安全审计 |
| 2 租户运营后台 | 租户管理员、客服主管 | 单租户业务运营与配置 | 工作台 / 客服与组织 / 客户中心 / 知识库 / AI 配置 / 渠道开放 / 数据运营 / 设置 |
| 3 PC 客服工作台 | 客服人员 | 会话接待主战场 | 三栏布局：会话列表 / 消息流 / 客户信息 |
| 4 客户 Web 入口 | 客户 | 咨询入口 | Web Widget + 独立聊天窗口 |
| 5 登录与账号体系 | 全角色 | 统一认证与权限 | 登录 / 注册 / 密码 / 个人中心 |

## 3. 核心流程与状态机

### 3.1 会话状态机

NEW → AI_HANDLING → QUEUED → HUMAN_HANDLING → TRANSFERRED → ENDED → EVALUATED

### 3.2 租户初始化流程（上线必经）

创建租户 → 首次登录改密 → 创建客服团队 → 上传知识库 → 配置 AI → 发布客服入口 → 客户咨询。

### 3.3 客户咨询主流程

Web 入口 → 渠道适配 → AI 接待（意图→RAG→LLM）→ AI 护栏 → 路由/转人工 → 客服摘要接管 → 结束 → 评价 → 运营统计。

## 4. 权限与安全

- RBAC + Tenant 双重约束，JWT 携带 user_id/tenant_id/role/permissions；
- 敏感字段脱敏、数据导出独立权限、操作审计；
- 关键操作可回滚，租户未初始化时客服入口不可见。

## 5. 非功能要求

| 编号 | 要求 | 指标 |
| --- | --- | --- |
| F-040 | 性能 | 首屏≤2s、消息≤500ms、AI≤3s、并发≥5000 |
| F-041 | 安全 | JWT/2FA/HTTPS/WSS/AES-256/RBAC/租户隔离 |
| F-042 | 可用性 | 系统≥99.9%、消息≥99.99%、WCAG 2.1 AA |
| F-043 | 扩展 | 微服务/模块化/插件化渠道/水平扩容 |
| F-044 | 运维 | Prometheus/Grafana/ELK/备份/告警 |

## 6. 二期规划

AI 能力（问答/多轮/转人工/辅助/质检）、知识库 RAG、客服运营（排班/技能组/绩效/分群/路由/报表）、渠道开放、语音消息。
